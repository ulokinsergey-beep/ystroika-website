# SEO + AEO/GEO архитектура сайта У-Стройка

> Дата: 2026-06-09. Документ: полная архитектура поискового продвижения сайта `ystroika.ru`
> под классический SEO (Яндекс/Google) и AEO/GEO (ответы AI-движков: ChatGPT, Perplexity,
> Яндекс Нейро, Google AI Overviews).
> Источник каталога: `tmp/tree.txt` (распарсен из Excel «Структура Каталога»).
> Бизнес-контекст: `docs/project-roadmap.md`.
>
> **Принцип всего документа:** для каждой страницы/блока указано не только «что», но и
> «зачем для SEO» (классическая выдача) и «зачем для AI» (цитирование в ответах нейросетей).

---

## Легенда сокращений

- **SEO** — оптимизация под классическую поисковую выдачу (позиции, сниппеты Яндекс/Google).
- **AEO** (Answer Engine Optimization) — оптимизация под цитирование в ответах AI (прямой ответ, факты, структура).
- **GEO** (Generative Engine Optimization / гео-продвижение) — здесь используется в двух смыслах: (а) попадание в генеративные ответы; (б) географическое продвижение по городам МО. По контексту понятно какой.
- **Интент** — намерение пользователя: коммерческий (купить/заказать), информационный (узнать), навигационный, транзакционный.
- **Сущность (entity)** — объект знаний, который понимает поисковик/AI: компания, бренд, категория товара, услуга, город.

## 7. ТРЕБОВАНИЯ К КОНТЕНТУ ДЛЯ GEO (как писать, чтобы цитировал AI)

1. **Прямой ответ в первых 2–3 абзацах** (40–80 слов) — AI извлекает начало.
2. **Чёткие определения** терминов (выделять, давать одной фразой).
3. **Структура H2/H3** под под-вопросы; один H2 = один вопрос.
4. **Списки, таблицы, сравнения** — машиночитаемо, легко извлекается.
5. **Авторство и экспертность**: автор-эксперт, опыт, «проверено мастером».
6. **Источники, методология, ограничения** — где цифры, как считали, когда не подходит.
7. **FAQ-блок** в конце каждого материала (FAQPage-разметка).
8. **Краткий вывод** («Коротко: …»).
9. **Без воды** — факт, а не «качественные материалы по доступным ценам».
10. **Разделять факты / выводы / рекомендации** явными подзаголовками.
11. **Внутренние ссылки** между связанными материалами и на коммерцию.
12. **schema.org** на каждом материале (см. §8). + дата публикации и обновления.

| **ItemList** | разделы/листинги | список товаров | itemListElement |
| **Product + Offer** | карточка товара | rich-сниппет цена/наличие | name, brand, image, offers(price, availability), aggregateRating |

| **Person** | авторы, команда | E-E-A-T авторство | name, jobTitle, worksFor |
| **WebPage** | каждая | тип страницы | name, description, breadcrumb |

## 11. ПЛАН ВНЕДРЕНИЯ (90 дней)

**0–30 дней — фундамент:** финализировать структуру (этот документ) + URL-схему; собрать семантику (коммерч. кластеры на каталоге); довести **главную** и **8 разделов каталога** + **6 услуг** до 1-в-1 Figma с SEO-текстами; базовая техническая SEO (мета, canonical, sitemap.xml, robots.txt, JSON-LD Organization/LocalBusiness/Breadcrumb).

**31–60 дней — контент+доверие:** запустить **базу знаний** (10–15 сравнений/гайдов под §5–6); **FAQ-хаб** (расширить 6→40+); оформить **кейсы** (6) и **отзывы** (107 + AggregateRating); внутренняя перелинковка (хаб→статья→товар→услуга); schema.org Article/FAQ/HowTo/Product.

**61–90 дней — рост+AEO/GEO:** расширение контента (ещё 15–20 статей); **гео-страницы** по городам МО; обновление материалов (даты); анализ индексации (Я.Вебмастер/GSC); проверка видимости в AI-поиске (запросы в ChatGPT/Perplexity/Нейро по ядру); улучшение конверсии (A/B форм/CTA).
