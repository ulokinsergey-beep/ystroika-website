## Main Gaps

1. Yandex regional layer needs strengthening.
   - Main delivery page exists.
   - Dedicated Moscow and Moscow Oblast delivery pages were missing before this audit pass.

2. URL standard must be fixed.
   - Current site uses Russian transliterated URLs: `/dostavka/`, `/kontakty/`, `/oplata/`.
   - Architecture docs previously suggested English URLs like `/delivery/`.
   - For the real site, keep the existing Russian URL style to avoid duplicates.

3. Filter URLs need Yandex cleanup rules.
   - Catalog subcategory page uses query params: `brand`, `sort`, `per_page`, `page`, `price_min`, `price_max`.
   - These should not become uncontrolled duplicate SEO pages.
   - `robots.txt` should use Yandex `Clean-param`.

4. Yandex verification is empty.
   - `BaseLayout.astro` contains an empty `yandex-verification` meta tag.
   - Add the real verification token only when it is available.

5. Some planned content collections are empty.
   - `vacancies`
   - `calculators`
   - This causes build warnings but does not break the build.

6. One working file is already dirty.
   - `src/pages/catalog/[category]/[subcategory].astro`
   - Current change disables price loading temporarily.
   - Do not overwrite this change without a separate decision.
