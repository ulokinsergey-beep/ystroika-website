# У-Стройка: как всё устроено (карта системы)

> Единый вход в проект. Детали — в профильных доках (ссылки внизу).
> Принцип: сайт читает только готовый СНИМОК; поставщики питают данные оффлайн;
> карточки обогащаются под SEO/AEO из лучших данных по всем источникам.

---

## 1. Слои (сверху вниз)

```
[ САЙТ ]            Astro (ystroika.ru), страницы 1-в-1 Figma.
   ▲               Читает ТОЛЬКО снимок (src/data/snapshots/...). Живых API из страниц нет.
   │
[ СНИМОК ]         catalog-snapshot-latest.json — стабильные данные для сайта (товар+цена+фото+характеристики).
   ▲
[ КОНТУР ДАННЫХ ]  scripts/catalog: adapters → normalizers → mapping(productId+категория)
   ▲                → pricing-rules → generate-snapshot → snapshot + report.
   │                Запуск оффлайн: n8n на NAS (cron + кнопка).
[ ПОСТАВЩИКИ ]     Döcke · КровАльянс · Grand Line (API каждого).
```

## 2. Поставщики (источники)

| Поставщик | Каталог | Цена | Фото | Характеристики | Статус |
|---|---|---|---|---|---|
| **Döcke** | ✅ | РРЦ | ✅ есть | ✅ богатые | ✅ в снимке (5770 тов., 3750 с фото) |
| **КровАльянс** | ✅ (широкий) | ✅ price + discounted | ❌ нет | габариты+бренд | ✅ API работает, адаптер не собран |
| **Grand Line** | ⏳ | ⏳ | ⏳ есть | ⏳ | ждём ключ/Swagger |

- **Döcke** — специализированный (гибкая черепица, сайдинг, водосток, фасад Döcke).
- **КровАльянс** — широкая номенклатура (металлочерепица, профнастил и др.), но без фото/описаний.
- **Grand Line** — металлочерепица/профнастил/сайдинг/водосток + фото.
- Правила API: `docs/krovalians-api-rules.md`, доступы — `credentials.md`/`.env`.

## 3. Управление ценой и номенклатурой

- **`productId`** — стабильный внутренний ID товара сайта (на нём держатся URL, карточка, SEO). Никогда не равен коду поставщика.
- **Mapping** — какой товар сайта = какие коды у поставщиков; приоритет источников (по бренду). Один товар из разных источников → ОДНА карточка.
- **pricing-rules.json** — какую цену показывать: РРЦ / наценка / округление / приоритет источника / ручной override. Нет цены → «по запросу» (без Offer).
- **Защита:** не выдумывать цену/наличие; снимок версионируется; при сбое API старый снимок не затирается.
- **Позже:** Directus — админка над mapping/pricing (правит человек); n8n — авто-обновление/уведомления.

## 4. SEO/AEO карточек (зачем весь контур)

Карточка «прокачивается» тем, что собирает ЛУЧШЕЕ по всем источникам:
- **Фото** — Döcke/Grand Line (у КА нет);
- **Габариты/бренд/ед.изм.** — КА + Döcke;
- **Характеристики/описание** — Döcke (богатые); у КА нет → дополняем своим контентом;
- **Цена** — по приоритету источников;
- **Schema** — Product/Offer (реальная цена → Offer), BreadcrumbList; листинг — ItemList;
- **AEO** — FAQ-блок, уникальное описание, перелинковка (доки `docs/seo/*`).

## 5. Текущее состояние сайта
- Готово 1-в-1 Figma: листинг (+нижние блоки), карточка товара, мега-меню каталога, услуги, калькуляторы.
- На сайте уже живут **цены и фото Döcke**; характеристики Döcke в карточке.
- КровАльянс-цены — после сборки адаптера; Grand Line — после ключа.

## 6. Инфраструктура запуска
- **n8n на NAS** (контейнер готов, том подключён) — генерирует снимок по расписанию/кнопке. Импорт workflow — за владельцем (3 клика).
- ПК тянет результат: `scripts/catalog/pull-from-nas.cmd`.
