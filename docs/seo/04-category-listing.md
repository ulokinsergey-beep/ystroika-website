# Детальная спека: РАЗДЕЛ КАТАЛОГА + ЛИСТИНГ ПОДКАТЕГОРИИ

> Два типа коммерческих страниц. ТЗ для верстки/копирайта. Пример — «Кровля» / «Металлочерепица».
> Обзор — `seo-architecture.md` §2. Это страницы P1-семантики (деньги сейчас) — высший приоритет.

# ЧАСТЬ A — РАЗДЕЛ КАТАЛОГА (`/catalog/{razdel}/`, хаб подкатегорий)

## Блок A1 — Хлебные крошки + H1
- **H1:** `Кровельные материалы в Москве и области` (раздел = ВЧ-кластер)
- **Ключи:** «кровельные материалы», «купить кровлю Москва». **Schema:** BreadcrumbList.
- **Готово:** один H1 с ВЧ; крошки Главная → Каталог → Раздел.

## Блок A2 — Краткое интро + подбор
- **Назначение:** прямой ответ «какие виды бывают» + ссылка на подбор/расчёт.
- **Контент:** 2–3 предложения: что в разделе, как выбрать, CTA подбора. **AEO:** «какие виды кровли».
- **CTA:** `Подобрать материал` / `Рассчитать количество`.

## Блок A3 — Сетка подкатегорий
- **Назначение:** навигация-хаб + перелинковка + ItemList.
- **Контент:** плитки всех подкатегорий (металлочерепица, гибкая черепица, профнастил, фальцевая, ондулин, композитная…) с фото, названием, кол-вом товаров.
- **Schema:** ItemList. **Перелинковка:** → листинги подкатегорий.
- **Готово:** все реальные подкатегории, alt у фото.

## Блок A4 — Бренды раздела
- **Контент:** логотипы брендов раздела → бренд-фильтр/бренд-страница. **Ключи:** «{материал} {бренд}».

## Блок A5 — SEO-текст (300–600 слов)
- **Назначение:** семантика + экспертность + AEO. Внизу страницы.
- **Контент:** как выбрать материал раздела, чем виды отличаются, на что смотреть, ссылки на гайды/сравнения базы знаний. H2/H3 под под-вопросы, таблица сравнения видов.
- **AEO:** информац. под-интенты. **Перелинковка:** → база знаний, → услуги монтажа.
- **Готово:** уникальный текст, не вода, с таблицей и ссылками.

## Блок A6 — FAQ раздела
- **Schema:** FAQPage. Вопросы: чем отличаются виды, что дешевле, что для дачи, доставка по МО.

## Блок A7 — CTA + доверие
- **CTA:** `Получить расчёт`. Блок доверия (9 лет, 107 отзывов). **Перелинковка:** → услуги, отзывы.

# ЧАСТЬ B — ЛИСТИНГ ПОДКАТЕГОРИИ (`/catalog/{razdel}/{podkat}/`)

## Блок B1 — Крошки + H1 + счётчик
- **H1:** `Металлочерепица` (+ при необходимости бренд/гео в title). **Ключи:** «металлочерепица купить цена».
- **Schema:** BreadcrumbList. Счётчик «N товаров». **Готово:** H1, крошки, кол-во.

## Блок B2 — Фильтр / фасеты (сайдбар)
- **Назначение:** UX-подбор + SEO-значимые фильтры как индексируемые URL.
- **Контент:** подкатегории, цена (слайдер), бренд, материал/покрытие/цвет/размер (когда появятся атрибуты).
- **Тех-SEO:** индексировать только значимые комбинации (категория+бренд, категория+город); сортировки/случайные фасеты — `noindex`/canonical (см. `13-technical-seo.md` §2).
- **Готово:** фильтр работает; индексация фасетов по правилам.

## Блок B3 — Сортировка + переключатель вид
- **Контент:** сортировка (цена/популярность), вид сетка/список (в Figma листинг = список — `figma-quality-rules`).

## Блок B4 — Карточки товаров (листинг)
- **Контент:** фото, название, бренд, рейтинг, цена/наличие (из КровАльянс API, CSR), CTA.
- **Schema:** ItemList + Product/Offer на карточках. **AEO:** «сколько стоит {товар}».
- **Готово:** карточки 1-в-1 Figma; цена/наличие из API; «вам понадобится».

## Блок B5 — Пагинация
- **Тех-SEO:** ЧПУ-пагинация, корректный canonical/rel, без дублей. **Готово:** по `13-technical-seo.md`.

## Блок B6 — «Часто ищут» / популярные фильтры
- **Назначение:** перелинковка + сбор НЧ-спроса. **Контент:** теги-ссылки (по бренду/цвету/цене).

## Блок B7 — SEO-текст листинга (внизу, 300–500 слов)
- **Контент:** про конкретный материал: характеристики, как выбрать, как рассчитать (ссылка на калькулятор), бренды. Таблица, FAQ.
- **AEO/перелинковка:** → калькулятор, → услуга монтажа, → сравнение в базе знаний.
- **Готово:** уникальный текст под подкатегорию.

## Блок B8 — FAQ листинга
- **Schema:** FAQPage. Вопросы: цена за м², расчёт количества, наличие, доставка, гарантия.

## Блок B9 — CTA + доверие + связанное
- **CTA:** `Получить цену и наличие` / `Рассчитать смету`. **Перелинковка:** → услуга, калькулятор, бренд, соседние подкатегории.

## Чек-лист готовности (раздел/листинг)
- [ ] 1-в-1 с Figma на 375/1280/1920.
- [ ] H1 один, ВЧ/СЧ-ключ; уникальные title/description; крошки.
- [ ] JSON-LD: BreadcrumbList + ItemList (+ Product/Offer на карточках, FAQPage).
- [ ] SEO-текст уникальный (300–600 / 300–500 слов) с таблицей и перелинковкой.
- [ ] Фасеты индексируются по правилам (`13-technical-seo.md`); цена/наличие из API.
- [ ] Перелинковка: подкатегории ↔ раздел ↔ бренд ↔ услуга ↔ калькулятор ↔ база знаний.
- [ ] CTA на подбор/расчёт; формы работают.
