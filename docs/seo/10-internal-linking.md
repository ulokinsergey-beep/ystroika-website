# Внутренняя перелинковка

> Без системы перелинковки сайт = набор страниц, а не экспертная сеть. Цель — связать сущности
> (товары, услуги, статьи, бренды, гео) в устойчивый граф, понятный поисковикам и AI.

## 1. Главный принцип
Каждая информационная статья должна вести минимум на:
- 1 коммерческую категорию;
- 1 услугу;
- 1 связанную статью;
- 1 форму заявки или калькулятор.

## 2. Типовые связки

### Статьи-сравнения
Пример: «Металлочерепица или профнастил»
Ссылки:
- /catalog/krovlya/metallocherepica/
- /catalog/krovlya/profnastil/
- /servisy/raschet-metallocherepicy/
- /uslugi/montazh-krovli/

### Статьи-инструкции
Пример: «Как рассчитать металлочерепицу»
Ссылки:
- /servisy/raschet-metallocherepicy/
- /catalog/krovlya/metallocherepica/
- /uslugi/montazh-krovli/

### Статьи про ошибки
Пример: «7 ошибок монтажа кровли»
Ссылки:
- /uslugi/montazh-krovli/
- /garantii/
- /proekty/
- /baza-znaniy/chek-list-priemki-krovli/

## 3. Хабовая структура
```
Главная → Каталог → Раздел → Подкатегория → Товар/заявка
Главная → Услуги → Услуга → Кейс → Заявка
Главная → База знаний → Статья → Категория/Услуга/Калькулятор
```

Это важно и для SEO, и для AI. Поисковики лучше понимают сайт, когда видят устойчивые связи между сущностями. Google прямо пишет, что структурированные данные помогают поиску понимать содержание страницы и сущности, но они должны соответствовать видимому контенту.

## 4. Правила реализации (для разработчика)
- Связанные ссылки — реальными `<a>` в HTML (видимы AI), не только JS.
- Якорные тексты — осмысленные («монтаж кровли под ключ»), не «тут»/«подробнее».
- Из каждой коммерческой страницы — ссылки на 2–3 связанные статьи базы знаний (обратная связка).
- Бренд-страница ↔ категории этого бренда (двусторонне).
- Гео-страница ↔ соответствующий раздел/услуга + соседние города.

## 5. Таблица анкорных текстов (эталон)
> Анкор = осмысленная фраза из кластера, ведёт на канонический URL (`01-sitemap-pages.md`).
> Не использовать «тут»/«подробнее»; не ссылаться разными анкорами на конфликтные URL.

| гибкая черепица цена | /catalog/krovlya/gibkaya-cherepica/ |
