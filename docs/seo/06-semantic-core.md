# Детальная спека: СЕМАНТИЧЕСКОЕ ЯДРО (рабочее)

> Разворот `seo-architecture.md` §6 в рабочее ядро: кластеры по реальным категориям
> каталога → целевая страница → приоритет → intent. Это вход для копирайта и
> кластеризации. Частотности (WS/«!»-точные) собираются в Wordstat/Key Collector
> на этапе продакшна — здесь зафиксированы кластеры, маски и приоритеты.

---

## 0. Как читать ядро

- **Кластер** — группа запросов под ОДНУ посадочную страницу (1 кластер = 1 URL).
- **Маска** — шаблон, из которого размножаются НЧ-хвосты (`{материал} {бренд} {гео}`).
- **Intent:** `C` коммерческий · `I` информационный · `S` сравнительный · `P` проблемный · `T` транзакционный · `Q` вопросный (conversational/AEO).
- **Приоритет:** P1 деньги сейчас · P2 прогрев/сравнение · P3 доверие/AEO.
- **Правило 1 кластер → 1 URL:** не каннибализировать. Сравнения и «как выбрать» — НЕ на коммерческой странице, а в базе знаний с перелинковкой.

| Гибкая черепица | гибкая черепица · мягкая кровля купить · черепица Shinglas/Технониколь · битумная черепица цена | **P1** |
| Профнастил | профнастил · профлист кровельный · профнастил для крыши/забора цена · С8/С21/НС35 | **P1** |
| Фальцевая кровля | фальцевая кровля · фальцевая крыша цена · кликфальц купить | P2 |
| Ондулин | ондулин · ондулин цена за лист · еврошифер купить | P2 |
| Композитная черепица | композитная черепица · композитная кровля цена | P3 |

## 4. ВОДОСТОК (раздел/листинг `/catalog/vodostok/`)

**Кластер (C, P1):** водосточная система · водосток купить Москва · водосточная система цена · водосток Grand Line/Docke/Технониколь · водосток металлический/пластиковый.
**Маски:** водосток для крыши {бренд} · желоб/труба водосточная цена · {цвет} водосток.
**Сравнения (S, P2):** металлический или пластиковый водосток · какой водосток выбрать для частного дома.
**Информационные/вопросные (Q, P3):** из чего состоит водосток · как рассчитать водосток · какой диаметр водостока нужен.
**Услуга-связка:** монтаж водостока цена → `/uslugi/montazh-vodostoka/`.

## 7. ГЕО-КЛАСТЕР (Local SEO, см. `15-local-seo.md`)

**Маска:** `{материал|услуга} {город МО}`. Базовые города: Москва, Орехово-Зуево, Ногинск, Электросталь, Павловский Посад, Балашиха, Богородский округ + «по Московской области».
Примеры: купить металлочерепицу Ногинск · кровельные материалы Орехово-Зуево · сайдинг Электросталь · доставка кровли по Московской области.
**Целевые URL:** гео-страницы / SEO-лендинги (IBLOCK 19), НЕ дубли — уникальный текст + локальные сигналы (адрес, доставка, NAP). **P2.**

## 8. ВОПРОСНЫЙ ПЛАСТ ДЛЯ AI (conversational, AEO/GEO-AI) ⭐

Прямой источник для FAQ-блоков, базы знаний и featured-сниппетов. Каждый → прямой ответ в первых 40–80 словах + FAQPage-разметка.

- сколько стоит покрыть крышу металлочерепицей
- что лучше для крыши дачи / частного дома
- как рассчитать сколько нужно металлочерепицы / сайдинга
- какой водосток выбрать для частного дома
- кому подходит фальцевая кровля
- как понять что пора менять кровлю
- какие риски у дешёвой металлочерепицы
- как выбрать подрядчика по кровле
- сколько служит гибкая черепица
- можно ли монтировать кровлю зимой

## 9. Карта «кластер → страница» (анти-каннибализация)

| Intent | Где живёт | НЕ дублировать на |
|---|---|---|
| C (купить/цена) | листинг подкатегории / карточка / услуга | в статьях и сравнениях |
| S (сравнение) | статья базы знаний | на листингах (только ссылка) |
| I (как выбрать) | гайд базы знаний | на коммерческих (только ссылка-перелинковка) |
| Q (вопрос) | FAQ-блок страницы + база знаний | размазывать по многим URL |
| Гео | гео-страница / SEO-лендинг | плодить тонкие дубли городов |

## Чек-лист готовности сем-ядра
- [ ] Каждый кластер привязан к одному URL (нет каннибализации).
- [ ] P1-кластеры покрыты коммерческими страницами первыми.
- [ ] Сравнительные/информационные вынесены в базу знаний с перелинковкой.
- [ ] Вопросный пласт разнесён по FAQ-блокам + базе знаний.
- [ ] Гео-маски ведут на уникальные гео-страницы, не на дубли.
- [ ] Маски хвостов готовы для парсинга частотностей на продакшне.
