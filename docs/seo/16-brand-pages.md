# Бренд-страницы (/brands/)

> Детальная спека типа страницы «Бренд». Обзор — `seo-architecture.md` §2.3.

## URL-структура
```
/brands/
  /brands/grand-line/
  /brands/docke/
  /brands/tehnonikol/
  /brands/metall-profil/
  ...по дилерским брендам в наличии
```

## Зачем нужны
- брендовые запросы («металлочерепица Grand Line Москва»);
- доверие (официальный дилер);
- связь с каталогом (товары бренда);
- AI лучше понимает ассортимент (entity бренда).

## Шаблон бренд-страницы
```
# {Бренд}: материалы для кровли и фасада

Блоки:
1. Что это за бренд (краткий прямой ответ — для AEO).
2. Какие категории бренда есть в продаже.
3. Популярные товары/разделы.
4. Кому подходит.
5. Плюсы и ограничения.
6. Сертификаты/дилерство, если есть (E-E-A-T).
7. FAQ (FAQPage-разметка).
8. Ссылки на категории (перелинковка в каталог).
9. Форма подбора (CTA).
```

## Schema.org
- Brand (как часть Product на товарах бренда);
- Organization / sameAs (дилерство);
- BreadcrumbList; FAQPage.

## Перелинковка
- Бренд ↔ его категории/подкатегории (двусторонне);
- Бренд ↔ сравнения брендов в базе знаний.

## Шаблон title / description
- **title (≤60):** `{Бренд} — кровля и фасад в Москве и области | У-Стройка`
- **description (≤160):** `{Бренд} в наличии: {категории}. Подбор, расчёт и доставка по Москве и МО. Цены и наличие — по запросу.`
> Без слова «официальный дилер», если дилерство не подтверждено документом.

## Блоки «категории бренда» и «популярные товары» (детализация)
- **Категории бренда:** плитки категорий, где есть товары этого бренда, со ссылками в каталог-фасет.
- **Популярные товары бренда:** 4–8 карточек ходовых позиций (фото, название, цена/«по запросу»), ссылка на полный список бренда.

## Связь с каталогом (бренд-фасет)
- Бренд-страница ведёт в каталог, отфильтрованный по бренду:
  `/catalog/krovlya/metallocherepica/?brand={slug}` (значимый фасет — индексируемый, см. `13-technical-seo.md` §13).
- Двусторонняя перелинковка: бренд ↔ его категории/подкатегории.

## Правило про дилерство (жёстко)
«Официальный дилер», логотип-партнёр, сертификат дилера — публиковать ТОЛЬКО при наличии подтверждающего документа (`fact-checking.md`, `08-eeat-trust.md` §3). Нет документа → нейтрально: «{Бренд} в продаже / в наличии».

## Ключи
{бренд} купить Москва; {бренд} {категория} цена; официальный дилер {бренд}; {бренд} или {конкурент}.
