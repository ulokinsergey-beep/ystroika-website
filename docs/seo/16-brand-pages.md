# Бренд-страницы (/brands/)

> Детальная спека типа страницы «Бренд». Обзор — `seo-architecture.md` §2.3.

## URL-структура
```
/brands/
  /brands/grand-line/
  /brands/docke/
  /brands/tehnonikol/
  /brands/metall-profil/
  ...по дилерским брендам в наличии
```

## Зачем нужны
- брендовые запросы («металлочерепица Grand Line Москва»);
- доверие (официальный дилер);
- связь с каталогом (товары бренда);
- AI лучше понимает ассортимент (entity бренда).

## Шаблон бренд-страницы
```
# {Бренд}: материалы для кровли и фасада

Блоки:
1. Что это за бренд (краткий прямой ответ — для AEO).
2. Какие категории бренда есть в продаже.
3. Популярные товары/разделы.
4. Кому подходит.
5. Плюсы и ограничения.
6. Сертификаты/дилерство, если есть (E-E-A-T).
7. FAQ (FAQPage-разметка).
8. Ссылки на категории (перелинковка в каталог).
9. Форма подбора (CTA).
```

## Schema.org
- Brand (как часть Product на товарах бренда);
- Organization / sameAs (дилерство);
- BreadcrumbList; FAQPage.

## Перелинковка
- Бренд ↔ его категории/подкатегории (двусторонне);
- Бренд ↔ сравнения брендов в базе знаний.

## Ключи
{бренд} купить Москва; {бренд} {категория} цена; официальный дилер {бренд}; {бренд} или {конкурент}.
