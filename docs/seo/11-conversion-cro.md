# CRO: конверсия и лидогенерация

> Сайт должен не просто ранжироваться, а продавать. Ниже — система CTA, форм и событий аналитики.

## 1. Главные CTA
- Получить расчёт кровли.
- Подобрать материал.
- Рассчитать смету.
- Заказать монтаж.
- Получить спецусловия для подрядчиков.
- Проверить смету подрядчика.
- Узнать наличие и цену.

## 2. CTA по типам страниц

### Главная
Основной CTA: Получить расчёт
Вторичный CTA: Позвонить / WhatsApp

### Категория
Основной CTA: Подобрать материал
Вторичный CTA: Рассчитать количество

### Подкатегория
Основной CTA: Получить цену и наличие
Вторичный CTA: Рассчитать смету

### Услуга
Основной CTA: Заказать расчёт работ
Вторичный CTA: Получить консультацию мастера

### Статья
Мягкий CTA: Получить расчёт под мой объект
Коммерческий CTA: Перейти в каталог / заказать монтаж

### Гео-страница
Основной CTA: Заказать доставку в {город}

## 3. Формы
**Короткая форма:**
- имя;
- телефон;
- комментарий.

**Расширенная форма:**
- тип объекта;
- площадь/размеры;
- материал;
- город доставки;
- нужен ли монтаж;
- файл проекта/фото.

## 4. События аналитики
- form_submit
- phone_click
- whatsapp_click
- calculator_start
- calculator_finish
- catalog_cta_click
- service_cta_click
- article_cta_click
