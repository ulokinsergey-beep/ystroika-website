# CRO: конверсия и лидогенерация

> Сайт должен не просто ранжироваться, а продавать. Ниже — система CTA, форм и событий аналитики.

## 1. Главные CTA
- Получить расчёт кровли.
- Подобрать материал.
- Рассчитать смету.
- Заказать монтаж.
- Получить спецусловия для подрядчиков.
- Проверить смету подрядчика.
- Узнать наличие и цену.

## 2. CTA по типам страниц

### Главная
Основной CTA: Получить расчёт
Вторичный CTA: Позвонить / WhatsApp

### Категория
Основной CTA: Подобрать материал

Вторичный CTA: Рассчитать смету

Коммерческий CTA: Перейти в каталог / заказать монтаж

### Гео-страница
Основной CTA: Заказать доставку в {город}

## 3. Sticky-кнопки на мобильной версии
Фиксированная нижняя панель на мобильных (важнейший конверсионный элемент):
- **Позвонить** (`tel:`) · **WhatsApp** · **Рассчитать** (→ форма/калькулятор).
- Не перекрывает контент; всегда видна при скролле; крупные тач-цели.
- В шапке на мобиле — телефон + WhatsApp всегда доступны.

## 4. Формы (B2C ≠ B2B)
**B2C — короткая форма (частник):**
- имя;
- телефон*;
- комментарий / что нужно.

**B2C — расширенная (расчёт под объект):**
- тип объекта, площадь/размеры, материал, город доставки, нужен ли монтаж, файл проекта/фото.

**B2B — форма подрядчика (`/spets-usloviya/`):**
- имя/компания;
- телефон*;
- объём/регулярность закупок;
- нужные категории;
- ИНН (опц., для договора/спецусловий).
> B2B-форма ведёт к менеджеру опта, не к рознице; отдельная логика обработки.
