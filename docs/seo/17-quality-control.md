# Детальная спека: КОНТРОЛЬ КАЧЕСТВА (приёмочные gate'ы)

> Финальный слой: как страница принимается в продакшн. Сводит воедино все
> чек-листы (02–16), `figma-quality-rules.md`, `fact-checking`, proof loop.
> Обзор — `seo-architecture.md` §12. Принцип: «готово» = прошло все gate'ы,
> а не «я сверстал».

---

## 0. Принцип приёмки
- Ведущий **сам проверяет** результат (в т.ч. работу субагента) ПЕРЕД показом владельцу — `figma-quality-rules.md` Правило 7.
- Не говорить «готово» без проверяемого доказательства (proof loop для рискового).
- Каждая страница проходит 6 gate'ов ниже последовательно.

---

## Gate 1 — ВИЗУАЛ 1-в-1 с Figma ⭐
Стандарт — `figma-quality-rules.md`.
- [ ] Сверка скриншот-в-скриншот на 375 / 1280 / 1920 (не только размеры — реальный визуал-дифф).
- [ ] Пропорции (flex, aspect), а не фикс-px (Правило 2); фото-объекты не перекрыты (Правило 1); зеркала/иконки корректны.
- [ ] Цвета/шрифты/отступы из токенов Figma; нет «придуманного» — сайт 100% по Figma.
- **Инструмент:** Playwright-скриншоты + ручная сверка с Figma-нодой.

## Gate 2 — КОНТЕНТ И КОПИРАЙТ
Стандарт — `09-content-guidelines.md`.
- [ ] Прямой ответ в первых 80 словах; H1 один; H2/H3 под под-вопросы.
- [ ] Контент per-page (не скопирован с другой страницы; нет placeholder/lorem) — Правила 3/4/5.
- [ ] Списки/таблицы/шаги/FAQ где нужно; tone of voice; нет воды.
- [ ] Цены реальные и РАЗНЫЕ; цифры подтверждены (`fact-checking`).

## Gate 3 — SEO/AEO ТЕХНИКА
Стандарты — `07-schema-org.md`, `13-technical-seo.md`.
- [ ] Уникальные title (≤60) / description (≤160); один H1; alt у изображений.
- [ ] JSON-LD по матрице типа страницы; прошёл Rich Results Test + Яндекс.Вебмастер.
- [ ] ЧПУ корректен; canonical; индексация/noindex по правилам; нет битых ссылок.
- [ ] Перелинковка по `10-internal-linking.md` (в коммерцию / база знаний / доверие).

## Gate 4 — ФУНКЦИОНАЛ
- [ ] Все формы отправляют заявку; валидация и ошибки корректны; согласие на ПД.
- [ ] Калькуляторы считают верно; CTA ведут куда заявлено.
- [ ] Цена/наличие из КровАльянс API (когда подключено) или честное «по запросу».
- [ ] Нет JS-ошибок в консоли; ссылки/якоря работают.

## Gate 5 — ПРОИЗВОДИТЕЛЬНОСТЬ И ДОСТУПНОСТЬ
Стандарт — `13-technical-seo.md`.
- [ ] Core Web Vitals в зелёной зоне (LCP/CLS/INP); изображения сжаты/lazy.
- [ ] Мобильная вёрстка без горизонтального скролла; тач-цели достаточны.
- [ ] Базовая a11y: контраст, alt, фокус, семантические теги.

## Gate 6 — ДОВЕРИЕ И LOCAL
Стандарты — `08-eeat-trust.md`, `15-local-seo.md`.
- [ ] Блок доверия + перелинковка в trust-страницы; реальные кейсы/отзывы.
- [ ] NAP консистентен; «Москва и область» где нужно; LocalBusiness на гео/контактах.
- [ ] Политика ПД и реквизиты доступны; HTTPS.

---

## Когда нужен proof loop (а не просто чек-лист)
По `proof-loop-routing.md`: страница затрагивает 3+ файла, меняет шаблон/поведение,
нужен build/скриншот/валидатор как доказательство, или прошлая попытка не удалась.
Тогда: spec → build → evidence → fresh verifier → fix → verifier до PASS.

## Чек-лист готовности страницы (итоговый)
- [ ] G1 Визуал 1-в-1 Figma (375/1280/1920).
- [ ] G2 Контент уникальный, факты верны, без заглушек.
- [ ] G3 Мета/H1/JSON-LD/ЧПУ/перелинковка — валидны.
- [ ] G4 Формы/калькуляторы/CTA работают.
- [ ] G5 CWV зелёные, мобайл ок, базовая a11y.
- [ ] G6 Доверие + Local + юр-минимум.
- [ ] (Если рисково) proof loop дал PASS свежим verifier.
- [ ] Ведущий проверил сам ПЕРЕД показом владельцу.
