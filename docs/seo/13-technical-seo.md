# Technical SEO

## 1. Индексация
- sitemap.xml для всех индексируемых страниц;
- robots.txt;
- canonical на всех страницах;
- noindex для технических/дублирующих фасетов;
- 301-редиректы со старых URL;
- корректная 404-страница.

## 2. Фасеты и фильтры
Индексировать только SEO-значимые фильтры:
- категория + бренд;
- категория + город, если есть спрос;
- категория + материал, если есть спрос.

Не индексировать:
- сортировки;
- случайные комбинации фильтров;
- параметры пагинации без смысла;
- внутренний поиск.

## 3. Производительность
- LCP < 2.5 сек;
- CLS < 0.1;
- изображения WebP/AVIF;
- lazy loading;
- минимизация JS;
- SSR/SSG где возможно.

## 4. Микроразметка
Проверять через Rich Results Test:
- Organization;
- LocalBusiness;
- BreadcrumbList;
- Product;
- Offer;
- Service;
- FAQPage;
- Article;
- Review;
- AggregateRating.

## 5. AI-доступность
- контент виден в HTML;
- важный текст не спрятан только в JS;
- таблицы и FAQ доступны в исходном HTML;
- llms.txt;
- понятные заголовки H1/H2/H3;
- структурированные блоки «Коротко», «Вывод», «FAQ».
