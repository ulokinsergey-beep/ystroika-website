# Аналитика и контроль результата

> Операционные метрики: что именно смотреть каждую неделю/месяц.

## 1. Инструменты
- Яндекс Метрика.
- Яндекс Вебмастер.
- Google Search Console.
- Bing Webmaster Tools.
- Microsoft Clarity.
- Сквозная таблица заявок.

## 2. SEO-метрики
- Индексация страниц.
- Показы.
- Клики.
- CTR.
- Средняя позиция.
- Страницы без трафика.
- Страницы с высоким показом и низким CTR.
- Страницы с заявками.

## 3. Конверсионные метрики
- Заявки с главной.
- Заявки с каталога.
- Заявки со страниц услуг.
- Заявки с базы знаний.
- Звонки.
- WhatsApp-клики.
- Конверсия калькуляторов.

## 4. AI / AEO / GAIO-метрики
Раз в месяц вручную проверять 30–50 контрольных запросов:

- «что лучше металлочерепица или профнастил»
- «как рассчитать металлочерепицу»
- «сколько стоит покрыть крышу металлочерепицей»
- «какой сайдинг выбрать для частного дома»
- «где купить кровельные материалы в Московской области»
- «как выбрать подрядчика по кровле»

Фиксировать:
- появляется ли сайт в ответах ChatGPT/Perplexity/Яндекс Нейро/Google AI;
- цитируется ли сайт;
- какие конкуренты цитируются;
- какие страницы используются;
- каких ответов не хватает на сайте.

## 6. UTM и источник заявки
- Размечать рекламные/внешние ссылки UTM (`utm_source/medium/campaign`).
- В форму заявки добавить скрытые поля: источник (`utm_*`), страница отправки, тип формы (B2C/B2B/калькулятор).
- В сквозной таблице заявок — колонки: дата, имя, телефон, страница, источник/UTM, тип формы, статус, сумма. Так видно, какие страницы и каналы дают деньги.

## 7. Еженедельный контроль
- новые страницы в индексе;
- ошибки 404;
- заявки;
- топ-страницы;
- просевшие страницы.

## 8. Ежемесячный контроль
- рост органики;
- конверсия по типам страниц;
- видимость по кластерам;
- новые темы для базы знаний;
- обновление старых статей.
