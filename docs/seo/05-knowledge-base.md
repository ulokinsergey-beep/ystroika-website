# ЧАСТЬ A — ХАБ БАЗЫ ЗНАНИЙ (`/baza-znaniy/`)

## Блок A1 — Крошки + H1
- **H1:** `База знаний о кровле и фасаде` (или `Полезные статьи`). **Schema:** BreadcrumbList.

## Блок A2 — Интро + поиск/фильтр по темам
- 2–3 предложения о пользе раздела; фильтр по рубрикам (Кровля / Фасад / Водосток / Монтаж / Выбор / Сравнения).

## Блок A3 — Рубрики (хаб-навигация)
- Плитки рубрик → страницы-рубрики или фильтр. **Schema:** ItemList. **Перелинковка:** → рубрики.

## Блок A4 — Лента статей
- Карточки: обложка, заголовок, рубрика, дата обновления, время чтения. Сортировка: свежие/популярные. **Schema:** ItemList.

## Блок A5 — Популярное / часто ищут
- Топ-гайды и сравнения (P2/P3-семантика) — перелинковка на ключевые ответы.

## Блок A6 — CTA в коммерцию
- «Нужен расчёт?» → услуга/калькулятор. База знаний всегда ведёт к конверсии.

# ЧАСТЬ B — ШАБЛОН СТАТЬИ (`/baza-znaniy/{slug}/`)

## Блок 1 — H1 + мета-шапка
- **H1:** точный заголовок под кластер (напр. `Металлочерепица или гибкая черепица: что выбрать`).
- **Шапка:** автор (E-E-A-T), дата публикации/обновления, время чтения, хлебные крошки.
- **Schema:** Article (+ author Person, datePublished, dateModified), BreadcrumbList.
- **Готово:** один H1, есть автор и дата обновления (Правило E-E-A-T).

## Блок 2 — Прямой ответ (TL;DR, 40–80 слов) ⭐
- **Назначение:** featured-snippet + цитирование AI. Главный AEO-блок.
- **Контент:** сразу ответ на вопрос статьи в первых 80 словах, без воды и вступлений.
- **AEO:** AI берёт первый абзац. **Готово:** прямой ответ выше первого H2.

## Блок 3 — Оглавление (для длинных гайдов)
- Якорная навигация по H2 → сниппеты с якорями + UX. **Schema:** часть WebPage.

## Блок 4 — Тело статьи (H2/H3 под под-вопросы)
- **Структура:** каждый H2 = отдельный под-вопрос кластера; машиночитаемые списки и **таблицы** (сравнения, характеристики, цены-ориентиры).
- **Семантика:** LSI, сущности (бренды, материалы, нормы). **AEO:** факты извлекаемы.
- **Готово:** H2 покрывают под-интенты; есть ≥1 таблица/список.

## Блок 5 — Сравнительная таблица (для статей-сравнений) ⭐
- **Назначение:** ядро S-интента — прямой ответ «что лучше».
- **Контент:** колонки = варианты, строки = критерии (цена, срок службы, монтаж, шум, вес, гарантия). Вывод «кому что подходит».
- **AEO:** таблицы отлично цитируются. **Готово:** объективная таблица + рекомендация по сценарию.

## Блок 6 — Визуалы (схемы/фото/инфографика)
- Иллюстрации с осмысленным `alt`. **Schema:** ImageObject. Усиливает E-E-A-T и дочитываемость.

## Блок 7 — Связка с продуктом/услугой (перелинковка в деньги) ⭐
- **Назначение:** перелить информационный трафик в коммерцию.
- **Контент:** блок «Где купить / Рассчитать / Заказать монтаж» → листинг, калькулятор, услуга.
- **Готово:** ≥2 ссылки в коммерческие страницы осмысленными анкорами.

## Блок 8 — FAQ статьи
- 3–6 Q&A по теме, прямой ответ 40–60 слов. **Schema:** **FAQPage**.

## Блок 9 — Об авторе / экспертность
- Кто автор (специалист по кровле/фасаду), опыт. **Schema:** Person/author. **E-E-A-T.**

## Блок 10 — Похожие статьи + хлебная навигация назад
- 3–4 связанные статьи (entity-граф) + возврат в рубрику. **Перелинковка:** → статьи, → рубрика.

## Типы статей и приоритет (из сем-ядра)

| Тип | Intent | Пример | Связка в деньги | Приор. |
|---|---|---|---|---|
| Сравнение ⭐ | S | металлочерепица или гибкая черепица | → 2 листинга + калькулятор | P2 |
| Гайд «как выбрать» | I | как выбрать сайдинг | → раздел/листинг | P2 |
| Гайд «как рассчитать» | I/T | как рассчитать металлочерепицу | → калькулятор | P2 |
| Стоимость/смета | Q | сколько стоит крыша под ключ | → услуга | P3 |
| Ошибки/проблемы | P | 7 ошибок монтажа кровли | → услуга монтажа | P3 |
| Выбор подрядчика | Q | как выбрать кровельщика | → услуги + доверие | P3 |

---

## Schema.org для базы знаний
- **Article** (headline, author Person, datePublished, dateModified, image) — на каждой статье.
- **FAQPage** — блок FAQ.
- **HowTo** — статьи «как рассчитать / как сделать» (по шагам).
- **BreadcrumbList** — крошки.
- **ItemList** — хаб и рубрики.

---

## Чек-лист готовности статьи (Definition of Done)
- [ ] Прямой ответ (TL;DR) в первых 80 слов.
- [ ] H2/H3 покрывают под-вопросы кластера; есть таблица/список.
- [ ] Для сравнений — объективная таблица + рекомендация по сценарию.
- [ ] Автор (Person) + дата публикации и обновления.
- [ ] FAQ с FAQPage-разметкой.
- [ ] Schema: Article (+HowTo где уместно) валидна.
- [ ] ≥2 перелинковки в коммерцию (листинг/калькулятор/услуга) + похожие статьи.
- [ ] Нет неподтверждённых цифр (см. `fact-checking`); CTA в конце.
- [ ] Уникальный текст, не рерайт-вода.
