## 3. СЕМАНТИЧЕСКОЕ ЯДРО + AEO/GEO (AI-поиск)

### 3.1. Семантическое ядро (кластеры под структуру каталога)
Бизнес: розница кровли/фасада/комплектующих, Москва и МО, B2C (частный застройщик) + B2B (подрядчик).

| Кластер | Ядро запросов (типы) | Куда |
|---|---|---|
| **Кровля** | металлочерепица/гибкая черепица/профнастил/фальцевая/ондулин + «купить Москва», «цена», «м2», бренды (Grand Line, Docke, ТЕХНОНИКОЛЬ, Металл Профиль) | разделы/подкатегории каталога |
| **Фасад** | сайдинг виниловый/металлический, фасадные панели, софиты + бренд/цена/город | каталог фасад |
| **Водосток** | жёлоба/трубы/воронки/кронштейны, водосточная система + бренд/цвет RAL | каталог водосток |
| **Заборы/ограждения, доборные, мансардные окна, вентиляция, утепление** | + «купить/цена/Москва» | разделы каталога |
| **Услуги** | монтаж кровли/фасада/водостока/стропил «под ключ», расчёт, замер, цена за м2 | /uslugi/* |
| **Сервисы** | калькулятор расчёта кровли/фасада/водостока онлайн | /servisy/* |
| **Информационные (блог/AEO)** ⭐ | «как выбрать металлочерепицу», «металлочерепица vs профнастил», «как рассчитать водосток», «чем крыть крышу дешевле», «какой сайдинг лучше», «срок службы X» | блог/статьи |
| **Гео (GEO)** | «кровельные материалы [город МО]» (Куровское, Орехово-Зуево, Ногинск, Электросталь…) | гео-лендинги (есть seo-landings.json + dostavka/*) |

**Приоритет контента:** информационный кластер (блог) + сравнения/гайды — самый дешёвый трафик и топливо для AEO. Реальных статей 2 → дописать 15–30 качественных под эти запросы.

### 3.2. AEO/GEO — оптимизация под AI-поиск (ChatGPT, Perplexity, Яндекс Нейро, Google AI)
AI-движки цитируют источники, дающие **прямой, структурированный, фактический ответ**.
- **Structured data (JSON-LD)** на каждый тип: Product+Offer, FAQPage, Article, HowTo (для расчётов/монтажа), LocalBusiness+Organization, BreadcrumbList, AggregateRating (отзывы 107 — актив!). Уже частично есть — довести до всех страниц.
- **Контент под «вопрос→ответ»**: каждая статья/FAQ начинается с краткого прямого ответа (40–60 слов), затем детали. Таблицы сравнения, маркированные списки, чёткие H2/H3 — AI легко извлекает.
- **Сущности (entity SEO)**: чёткая сущность компании (Organization), брендов, категорий товаров; единые названия, перелинковка.
- **E-E-A-T сигналы**: опыт 9 лет, сертифицированные специалисты, реальные отзывы 107, реквизиты, гарантии — выносить явно.
- **Технически для AI**: `llms.txt` (карта смыслов сайта), чистый семантический HTML, быстрый SSG, alt у картинок, OG/мета.
- **GEO**: гео-страницы доставки/услуг по городам МО (металлочерепица в Ногинске и т.п.) с LocalBusiness + areaServed.

## 4. ПЛАН ДЕЙСТВИЙ (по порядку, без переделок, с учётом лимита Figma)

**Принцип чередования:** Figma-дни (лимит свежий) → визуальная вёрстка 1-в-1 батчами. Не-Figma-дни (лимит исчерпан) → контент/SEO/данные/деплой. Так лимит никогда не простаивает и нет переделок.

**Этап 1 — закрыть начатое (Figma-день).** 4 услуги — свои фото; полная посекционная сверка главной/услуг/сервисов. Коммит.

**Этап 2 — контент/SEO (не-Figma-день).** Решить судьбу блог-черновиков; написать 10–15 SEO/AEO-статей по инф-кластеру (прямой ответ + таблицы + JSON-LD Article/FAQ/HowTo); расширить FAQ; описания брендов. Восстановить картинки (или новые).

**Этап 3 — инфо-страницы 1-в-1 (Figma-день).** Блог+деталь, новости+деталь, отзывы, проекты+деталь, вакансии, сертификаты, спец-условия, FAQ, поиск, 404/502, юр-страницы, карта сайта, cookies. Контент — уже извлечённый + дописанный (§2B). Маппинг к Figma, не переэкстракция.

**Этап 4 — каталог/товары (не-Figma + API-день).** Восстановить КровАльянс API → товары/цены/наличие; фильтр-фасеты (нужны атрибуты — обогащение данных); карточка товара доводка.

**Этап 5 — технический SEO + деплой.** JSON-LD по всем типам, sitemap/robots/canonical/OG, `llms.txt`; убрать крупные PDF из git → push → CI/CD на Timeweb.

**Этап 6 — рост.** Гео-лендинги по городам МО; новые статьи по сем-ядру регулярно; сравнения; личный кабинет (отдельная фича).

## 5. ВЗГЛЯД СВЫСОКА (стратегия)
- **Сильные стороны уже сейчас:** структура каталога, услуги/сервисы 1-в-1, 107 реальных отзывов (золото для доверия + AggregateRating), data-driven шаблоны, протокол качества.
- **Главные дефициты:** (1) блог-контент почти пуст → нет инф-трафика и топлива для AEO; (2) картинки контента потеряны; (3) товары/цены не подключены (API). Это три рычага роста.
- **Ставка на AEO/GEO** оправдана: ниша (стройматериалы + расчёт) идеальна для «вопрос→ответ» контента, который цитирует AI-поиск; конкуренция в инф-запросах ниже, чем в коммерческих.
- **Без переделок** достигается чередованием Figma/не-Figma дней и принципом «извлечение ⟂ презентация» (данные полные → вёрстка маппит).

## 6. АВТО-УЛУЧШЕННЫЙ ПРОМТ (рабочий протокол проекта)
```

- Лимит исчерпан → контент/SEO/данные/деплой (Figma не нужна).
Любая страница: 1-в-1 по визуалу Figma + реальный уникальный контент (не lorem, не повтор).
Контент: данные полным суперсетом отдельно от вёрстки (извлечение ⟂ презентация) — не переделывать.
SEO/AEO встроены сразу: прямой ответ в начале, H2/H3, таблицы, JSON-LD (Article/FAQ/Product/HowTo/LocalBusiness), alt, мета уникальные.
Проверка ДО показа владельцу: я сам сверяю каждую страницу ↔ Figma и числа данных (Правило 7), исправляю, потом показываю.
Соблюдать docs/figma-quality-rules.md.
```
