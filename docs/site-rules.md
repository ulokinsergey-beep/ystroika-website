# Правила сайта У-Стройка (живой документ)

> Бизнес-правила работы сайта и каталога — что показываем, как ведём себя при
> обновлениях, чего не делаем. Наполняется по ходу. При конфликте кода и этого
> документа — правило здесь главнее, код приводим к нему.
> Технические детали — `system-overview.md`, `catalog-pricing-architecture.md`.

---

## 1. Каталог и товары

1.1. **КровАльянс: не публикуем товары без цены.** Новый КА-товар без цены на сайт не выводится (у КА нет фото/описаний → это тонкая карточка, вредит SEO). *(реализовано: generate-snapshot.mjs)*

1.2. **«Липкое» правило при обновлении цен (раз в неделю).** Если КА-товар УЖЕ был на сайте и при обновлении потерял цену — **НЕ удаляем** его с сайта. Остаётся как «по запросу» (сохраняем URL и индексацию, не плодим 404). *(реализовано: сверка с прошлым снимком)*

1.3. **Не выдумывать цену и наличие.** Нет цены — показываем «по запросу» (без Offer в разметке). Остатки с сайта не показываем (`availability: unknown`).

1.4. **Тонкие/пустые карточки и категории не плодим** (SEO). Döcke-товары без цены остаются (у них есть фото + характеристики — они не тонкие).

1.5. **Характеристики — только реальные от поставщика**, ничего не дописываем. Нет данных — поле не показываем.

---

## 2. Цены

2.1. **Döcke** — цена продажи = **РРЦ** поставщика, округление до 10 ₽ вверх.

2.2. **КровАльянс** — цена продажи = поле **`price` (розница)**, округление до 10 ₽ вверх. (Не `discounted_price`.)

2.3. Источник цены при пересечении товара у разных поставщиков — по приоритету бренда *(будет в дедупе, A2)*.

---

## 3. Обновление данных

3.1. Обновление снимка — **раз в неделю** (или по кнопке) через n8n на NAS. Сайт читает только готовый снимок.

3.2. При сбое API поставщика **старый снимок не затирается** (latest пишется только без блокеров).

3.3. Снимок версионируется (история для отката).

---

## 4. Поставщики

4.1. **Döcke** — гибкая черепица, сайдинг, водосток, фасад Döcke. Есть фото + характеристики.

4.2. **КровАльянс** — широкая номенклатура. Есть цены + габариты + бренд. **Нет фото и описаний.**

4.3. **Grand Line** — подключается (ждём ключ). Есть фото.

---

## 5. SEO / AEO

5.1. URL карточки — по внутреннему `productId`, стабильный (не код поставщика).

5.2. Сайт 100% 1-в-1 по Figma (`figma-quality-rules.md`); факты — через `fact-checking`.

5.3. Полный SEO/AEO-стандарт — пакет `docs/seo/` (00–18).

---

## 6. Безопасность / доступы

6.1. Секреты (доступы поставщиков, NAS) — только в `credentials.md` / `.env` (gitignored). В репозиторий и публичные данные не попадают.
