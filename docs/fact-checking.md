# Fact-checking: проверка фактов и risky-claims (стандарт проекта У-Стройка)

> Чем подтверждать цифры и утверждения на сайте, прежде чем их публиковать.
> На этот файл ссылаются спеки `docs/seo/*` (02, 03, 08, 09, 16, 17).
> Связан с навыком `fact-checking` (строгая проверка). Принцип: **нет
> подтверждения → не публикуем утверждение** (или смягчаем формулировку).

---

## 0. Зачем
Ложный факт на коммерческом сайте — это и репутация, и риск по рекламному
законодательству РФ (недостоверная реклама), и потеря доверия AI/поисковиков.
Лучше нейтральная формулировка, чем красивое, но недоказуемое утверждение.

## 1. Что обязательно проверять (risky-claims)
| Утверждение | Чем подтверждать | Если нет подтверждения |
|---|---|---|
| «9 лет на рынке» | дата регистрации юрлица / первые документы | «много лет» убрать конкретику или не писать |
| «107 отзывов», «рейтинг 5.0» | реальная выгрузка отзывов (IBLOCK 13) / карточка на Картах | не указывать число/рейтинг |
| «30 000+ позиций» | выгрузка каталога / КровАльянс API | «широкий ассортимент» без числа |
| «доставка за 1 день» | реальные условия логистики по зонам МО | «быстрая доставка», уточнить зоны |
| «гарантия лучшей цены» | реальные условия акции/политики | убрать или заменить на конкретное условие |
| «официальный дилер {бренд}» | дилерский договор/сертификат | «{бренд} в наличии / в продаже» |
| «сертифицированные мастера» | сертификаты/удостоверения | «опытные монтажники» |
| цена «от X ₽/м²», сроки «5–7 дней» | прайс/регламент работ | «рассчитывается по объекту» |
| характеристики товара (срок службы, гарантия) | паспорт/сайт производителя | не указывать цифру |

## 2. Источники истины (в порядке доверия)
1. Документы компании (договоры, сертификаты, реквизиты).
2. Внутренние выгрузки: каталог (Excel), КровАльянс API, IBLOCK 07/10/13/14/25.
3. Официальные сайты/паспорта производителей (характеристики товаров).
4. Публичные профили компании (Яндекс.Бизнес, 2ГИС) — для NAP/отзывов.
> Память модели и «общеизвестное» — НЕ источник. Свежие/спорные данные — искать
> (`search-and-read-web`: Tavily для поиска, Firecrawl для чтения), отделять факт
> от предположения, сохранять источник.

## 3. Процесс перед публикацией
1. Выписать все цифры и сильные утверждения со страницы.
2. По каждому — найти источник из §2.
3. Подтверждено → публикуем как есть. Не подтверждено → смягчаем/убираем.
4. Спорные/внешние данные — сохранить ссылку на источник в задаче.
5. Не публиковать выдуманные цены/рейтинги/наличие (см. `07-schema-org.md` §0).

## 4. Формулировки-замены (когда факта нет)
- точное число → «широкий выбор», «большой ассортимент»;
- «дешевле всех» → «конкурентные цены», «цена по запросу»;
- «лучшие» / «№1» → конкретная выгода вместо превосходной степени;
- «официальный дилер» → «{бренд} в наличии».

## 5. Чек-лист fact-check (gate)
- [ ] Все цифры на странице имеют источник из §2.
- [ ] Нет «официальный дилер/сертифицирован» без документа.
- [ ] Цены/наличие согласованы с состоянием каталога/API.
- [ ] Превосходные степени убраны или подтверждены.
- [ ] Спорные внешние факты — со ссылкой на источник.
- [ ] Schema.org не содержит выдуманных price/rating/review.
